# Raspberry

Acest folder conține componenta care simulează sau transmite date pentru sistemul de monitorizare.

## Rol

- generează sau preia locații pentru vehicule;
- interacționează cu backend-ul prin API;
- ajută la testarea fluxului de date în mediu local sau de dezvoltare.

## Fișiere principale

- main.py – punctul de intrare al clientului.
- api_client.py – client pentru comunicarea cu serverul.
- movement.py – logică de simulare a mișcării.
- config.py – configurări locale.
